# Geologic Time Scale Interactive Explorer

## 概要
先カンブリア代からパレオゾイク・メソゾイク・センゾイクまで、46億年の地質年代スケールをインタラクティブに探索できるビジュアライザ。

## 機能
- 縦スクロール型タイムライン（上=現在、下=46億年前）
- 4つの累代（Hadean, Archean, Proterozoic, Phanerozoic）+ 複数の代・紀を色分け表示
- 国際地質年代カラースキーム準拠の色分け
- 各地質時代をクリック → ポップアップで時代範囲・代表生物・主要イベントを解説
- 5大絶滅イベント（オルドビス紀末・デボン紀末・ペルム紀末・三畳紀末・K-Pg）を赤マーカーで表示
- ズームスライダー：46億年全体表示 → 顕生代(541Ma)のみ表示まで無段階調整
- 各時代の持続時間を地球史全体の割合でバー表示

## 使い方
1. タイムラインの任意の時代バーをクリックして詳細ポップアップを開く
2. ズームスライダーを右に動かすと顕生代に拡大表示
3. 赤い破線マーカーで大量絶滅イベントの位置を確認
4. ESCキーまたはモーダル外クリックで閉じる
